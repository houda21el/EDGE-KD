# EDGE-KD: Explainability-Driven Knowledge Distillation for Chest X-Ray Classification

This repository contains the **Google Colab notebook** implementing **EDGE-KD**, a novel framework that integrates explainability into knowledge distillation for medical image classification.

**EDGE-KD** leverages **TS-EXM** (Texture–Shape Explainable Method) to extract and fuse saliency maps that capture texture and shape features. These maps guide the student model during training, improving both **performance** and **interpretability**.
